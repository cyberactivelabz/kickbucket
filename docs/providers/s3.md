# Amazon S3

Provider name: `s3`. Source: `internal/engine/providers/s3/s3.go`.

## URL formats

Kickbucket uses virtual-hosted-style URLs, with the candidate name as the bucket:

| Probe | Method | URL |
|---|---|---|
| Object (with `--object-path`) | `HEAD` | `https://<bucket>.s3.amazonaws.com/<object-path>` |
| List | `GET` | `https://<bucket>.s3.amazonaws.com?list-type=2&max-keys=0` |

The bucket name is path-escaped. A leading `/` is added to the object path if it is missing.

When the provider is configured with a custom endpoint (the `Endpoint` field of `s3.Config`, used by the Go library and tests), it switches to path-style URLs: `<endpoint>/<bucket>/<object-path>` and `<endpoint>/<bucket>?list-type=2&max-keys=0`.

## How access is detected

| Step | Response | Result |
|---|---|---|
| Object `HEAD` | `2xx` | `public read` |
| Object `HEAD` | anything else | continue to the list probe |
| List `GET` (ListObjectsV2, zero keys) | `2xx` | `listable` |
| List `GET` | `401` or `403` | `private` |
| List `GET` | `404` | error `bucket "<name>" not found` |
| List `GET` | any other status | error `unexpected S3 status <code>` |

Responses `429` and `503` are retried up to three attempts in total. See [Providers](/providers/) for the shared behaviour.
